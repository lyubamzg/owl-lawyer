УСТАНОВКА «СОВА-ЮРИСТ» НА WINDOWS — ПО ШАГАМ
=============================================

Сначала установите четыре программы (если их уже нет), потом
запустите установщик пакета. Все ссылки — в файле
windows-загрузки.txt рядом с этой инструкцией.


1. PYTHON (основа всего приложения)
-----------------------------------
1) Откройте в браузере ссылку на python.org из windows-загрузки.txt.
2) Нажмите большую жёлтую кнопку «Download Python 3.x.x».
3) Запустите скачанный файл python-3.x.x-amd64.exe.
4) В САМОМ ПЕРВОМ окне установщика:
      ✓ поставьте галочку «Add python.exe to PATH»  ← обязательно!
      затем «Customize installation» и на втором шаге
      ✓ убедитесь, что «tcl/tk and IDLE» включён (галочка).
5) Install → дождитесь «Setup was successful».


2. ПОДПИСИ БИБЛИОТЕКИ (ставит сам установщик пакета)
----------------------------------------------------
Это openpyxl (Excel-таблицы) и python-docx (Word-документы).
Установщик пакета ставит их сам — отдельно ничего делать не нужно.


3. TESSERACT OCR (распознавание сканов Ф-9)
-------------------------------------------
1) Скачайте tesseract-ocr-w64-setup-... по ссылке из windows-загрузки.txt.
2) В установщике: Next → Next →
3) В окне выбора компонентов («Choose Components») поставьте галочку
      ✓ Russian   ← ВАЖНО! Без него справки не распознаются.
4) Install → Finish.
Путь по умолчанию: C:\Program Files\Tesseract-OCR — не меняйте.


4. POPPLER (разрезает PDF на страницы)
--------------------------------------
1) Скачайте по ссылке из windows-загрузки.txt файл
   Release-xx.zip (poppler-windows).
2) Создайте на диске C папку C:\poppler и распакуйте архив в неё,
   так чтобы внутри получилось C:\poppler\...\bin\pdftoppm.exe
3) Добавьте папку bin в PATH:
   • Win+R → введите sysdm.cpl → Enter
   • вкладка «Дополнительно» → «Переменные среды»
   • в нижнем списке выберите «Path» → «Изменить» → «Создать»
   • введите путь к bin, например C:\poppler\poppler-24.08.0\Library\bin
   • OK → OK → OK.


5. LIBREOFFICE (просмотр таблиц и печать)
-----------------------------------------
1) Скачайте по ссылке из windows-загрузки.txt файл .msi
2) Запустите: Далее → Далее → Установить.
(Если на компьютере есть Microsoft Word и Excel — LibreOffice всё
равно нужен: приложение вызывает именно его.)


6. УСТАНОВКА САМОГО ПРИЛОЖЕНИЯ
------------------------------
1) Двойной клик по УСТАНОВКА-Виндовс.bat в папке пакета.
2) Скрипт проверит всё выше и напишет «ОК» напротив каждого пункта.
   Если что-то не ОК — он напишет, ЧТО именно, и где взять;
   установите недостающее и запустите .bat ещё раз.
3) В конце откроется окно «Сова-юрист», а на рабочем столе появятся
   три ярлыка: «Сова-юрист», «1 Загрузить данные»,
   «2 Собрать документы».


7. ЧТО ДАЛЬШЕ
-------------
Проверьте работу по Чек-лист-проверки.txt (15 минут).
В окне приложения два раздела: «РАЗДЕЛ ЖКУ» и «СЕМЕЙНОЕ ПРАВО»
(иски о расторжении брака: сканы → анкета → готовый иск).
Реальные данные (Книги, «Портянка», сканы) в пакет не входят —
переносите их на новый компьютер сами, с учётом правил
работы с персональными данными.
