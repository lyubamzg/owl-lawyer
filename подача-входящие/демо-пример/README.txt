ДЕМО-ПРИМЕР (полностью вымышленные данные)
=========================================

Здесь лежат два файла, чтобы можно было проверить приложение
«под ключ» и не загружать настоящие документы:

  • Портянка (демо-вымышленная).xlsx — расчёт бухгалтерии
    на 5 лицевых счетов (000000101–000000105);
  • Ф-9 (демо-справки).pdf — 5 справок о регистрации, по одной
    на каждый лицевой счёт.

Все данные вымышлены: компания «Рога и Копыта», адреса в
«Примерной области», паспорта, печать и подписи — выдуманные.
Суммы долга и пени — произвольные, для примера.

Как проверить:
  1. Скопируйте оба файла из этой папки в «подача/входящие»
     (или в папку, указанную в диалоге загрузки).
  2. Нажмите «1 Загрузить данные».
  3. Приложение соберёт книгу ввода: 5 заявлений, 7 должников
     и 5 привязанных справок Ф-9.
  4. Нажмите «2 Собрать документы» — получите 6 документов
     (судебные приказы по одному на каждое лицо из графы
     «собственник/наниматель» и два иска).

После проверки файлы можно удалить.
