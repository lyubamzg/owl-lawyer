ЭТА ПАПКА — «почтовый ящик» для данных бухгалтерии.

Сюда кладите свежие файлы перед нажатием «1 Загрузить данные»:
  • Портянка*.xlsx — расчёт бухгалтерии (Excel);
  • Ф-9*.pdf      — сканы справок о регистрации.

Лучше называть сканы по одному: «Ф-9 ЛС065005800.pdf» — тогда
каждая сама привяжется к нужному лицевому счёту. Если сканируете
одным файлом, приложение создаст «Ф-9 индекс.xlsx» — впишите в него
номера лицевых счетов напротив страниц, сохраните и запустите
«1 Загрузить данные» ещё раз.

Старые файлы можно оставлять здесь — импорт берёт самые свежие,
но чтобы не путаться, лучше переносить использованные в архив.
