ЧЕК-ЛИСТ ПРОВЕРКИ УСТАНОВКИ
===========================

Проходите по пунктам и отмечайте: ок / не ок. Если «не ок» —
запишите, о чём предупредило приложение, и сообщите разработчику.

LINUX И WINDOWS
---------------
1. Ярлыки на рабочем столе: «Сова-юрист», «1 Загрузить данные»,
   «2 Собрать документы». Ярлык приложения — сова.        [ ]
2. Открыть «Сова-юрист»: появилось окно с 4 кнопками и журналом,
   иконка — сова, ничего не пропало со шрифтом.            [ ]
3. Нажать «Создать новую таблицу» → открылась книга в
   LibreOffice с листами Инструкция/Настройки/Заявления/Должники.
   (Закрыть без сохранения.)                               [ ]
4. Папка «filing/incoming» существует рядом с папкой «OwlLawyer»,
   в ней README о том, что сюда класть.                    [ ]

WINDOWS ДОПОЛНИТЕЛЬНО
---------------------
5. Нажать «2 Собрать документы» (на демо-книге из пакета):
   в журнале прошла сверка, папка output открылась, документы
   открываются в Word/LibreOffice, шрифт Times New Roman.  [ ]
6. Положить в «filing\incoming» пробные Портянку и Ф-9,
   нажать «1 Загрузить данные»: в чёрном окне русский текст
   читаем (не «кракозябры»), книга создалась.              [ ]
7. Двойной клик «1 Загрузить данные.lnk» и «2 Собрать
   документы.lnk»: запускаются, окно не закрывается само.  [ ]
8. Распознавание Ф-9: если скан был один общий — появился
   «f9-index.xlsx» с просьбой вписать ЛС. Автоопределение:
   ЛС внутри текста каждой справки распознаётся сам; справка
   привязана к своему ЛС на листе «Ф-9 справки», в готовый
   документ её текст не вставляется.                        [ ]

РАЗДЕЛ «СЕМЕЙНОЕ ПРАВО» (новый)
-------------------------------
9. В окне приложения ряд вкладок «[ ▼ РАЗДЕЛ ЖКУ ] [ ▶ СЕМЕЙНОЕ
   ПРАВО ]» (левая развёрнута, правая свёрнута); по клику вкладки
   раскрываются три кнопки: Загрузить сканы / Открыть анкету /
   Собрать исковое заявление. Раскрытие одной закрывает другую. [ ]
10. Нажать «1. Загрузить сканы документов» без сканов: создалась
    «family-questionnaire.xlsx» (листы Инструкция/Дело/Дети/Сканы),
    в журнале — пояснение, какие имена файлов ожидать.          [ ]
11. Демо-прогон всего цикла: python3 generate_family_claim.py --демо
    (Windows: py -3 generate_family_claim.py --демо) → в папке
    «output-family» иск .docx + «validation-report-family.txt», в
    отчёте только предупреждения, без ошибок.                   [ ]
12. Открыть демо-иск в Word/LibreOffice: шапка правым краем, три
    пункта «ПРОШУ» (расторжение брака, алименты, место жительства
    детей), подпись ИСТЦА (без «представителя по доверенности»). [ ]

РАЗДЕЛ «ЗАЩИТА ПРАВ ПОТРЕБИТЕЛЯ» (новый)
----------------------------------------
13. В ряду вкладок есть третья вкладка; по клику — три кнопки
    (Загрузить сканы / Открыть анкету / Собрать иск).           [ ]
14. Демо-прогон: python3 generate_consumer_claim.py
    --демо → в «output-consumer» иск .docx с ПРОШУ
    (требование + неустойка/моральный вред — по анкете + штраф
    50 %), пошлина «не уплачивается», приложения без дублей.    [ ]
15. Открыть «consumer-questionnaire.xlsx»: лист «Проблематика» —
    строка = абзац описательной части иска (заполняет юрист).  [ ]

После проверки демо-документы из «output» и «output-family», и
«output-consumer» можно удалить.

16. Нажать любую кнопку «Загрузить…»: сначала открылось окно
    «Какие документы загрузить?» — файлы видны все форматов,
    можно выделить несколько; при отмене — в журнале «загрузка
    отменена», ничего не сломалось.                         [ ]
17. При загрузке «Портянки» рядом со старой книгой появился
    «housing-input-backup <дата>.xlsx».           [ ]
18. Пошаговый режим: после успешного этапа (загрузка/открыть/
    собрать) в журнале справа появилась зелёная кнопка
    «▶ ПРОДОЛЖИТЬ»; она запускает следующий этап раздела; после
    сбора документов вместо неё — «✔ Все этапы раздела
    выполнены». При ошибке этапа кнопка НЕ появляется.       [ ]
19. Лица по графе Ф-9: открыть книгу (лист «Ф-9 справки», колонка
    5) — там «Фамилия И.О.» из графы «собственник и/или
    наниматель». Собрать документы: заявлению с ДВУМЯ лицами в
    графе соответствуют ДВА файла «(1 из 2)» и «(2 из 2)» с
    одним лицом в каждом (СП), а иску — ОДИН файл, где
    собственник и совершеннолетние зарегистрированные в шапке
    «Ответчик(и)», несовершеннолетние отсутствуют.          [ ]
20. Привязка страниц Ф-9 к ЛС: в «Отчёте-сверки.txt» (импорт) по
    каждой странице видно, к какому ЛС она привязана (по угловому
    номеру на скане); непонятные страницы — в листе «Ф-9 не
    привязаны», а не «наугад».                                 [ ]
21. Частичная сборка: если одно заявление заполнено с ошибкой —
    в «Отчёте-сверки.txt» (сбор) перечислены только ПРОПУЩЕННЫЕ
    заявления с причинами, остальные .docx собраны в «output».  [ ]
22. ДЕМО-НАБОР: скопировать папку «incoming/demo»
    (Портянка + «f9-demo.pdf») в «filing/incoming»,
    нажать «1 Загрузить данные»: в журнале — «распознано страниц: 5,
    привязано: 5», каждая справка привязана к своему ЛС, в отчёте
    сверки 0 ошибок. Данные в демо-наборе ВЫМЫШЛЕНЫ (компания
    «Рога и Копыта», печать нарисована).                     [ ]
