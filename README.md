# 🦉 Сова-юрист

Автоматизация юриста по взысканию задолженности за ЖКУ. Локальное desktop-приложение
на Python + Tkinter: превращает расчёт бухгалтерии и сканы справок Ф-9 в готовые
судебные приказы и исковые заявления.

Работает **только на вашем компьютере**. Интернет не используется, персональные данные
никуда не отправляются.

Три раздела:

| Раздел | Что делает |
|---|---|
| **Жилищное право (ЖКУ)** | Расчёт бухгалтерии («Портянка») + сканы справок Ф-9 → таблица ввода → судебные приказы и иски (.docx) + реестр и отчёт сверки. Номер лицевого счёта распознаётся **автоматически** из текста каждой справки; страница привязывается к своему счёту, а не «наугад». |
| **Семейное право** | Сканы (паспорт истца, свидетельство о браке, свидетельства о рождении детей) → анкета → иск о расторжении брака, взыскании алиментов и определении места жительства детей. |
| **Защита прав потребителя** | Сканы (паспорт, претензия, чек) → анкета → иск: возврат денег / замена / устранение недостатков + неустойка + моральный вред + штраф 50 %. |

## Установка

### Linux (Debian / Ubuntu / Mint)

```bash
bash install-linux.sh
```

Скрипт поставит зависимости, скопирует программу в `~/Desktop/OwlLawyer`, создаст
ярлыки «Сова-юрист», «1 Загрузить данные», «2 Собрать документы» и проверит
цепочку демо-прогоном.

Если зависимости уже стоят: `SOVA_SKIP_APT=1 bash install-linux.sh`

### Windows

Запустите **`SOVA-Setup-0.2.0-x64.exe`** (Windows 10/11, x64).
Мастер проверит Python/Tkinter, подготовит отдельное окружение с библиотеками
и предложит установить отсутствующие Tesseract OCR, Poppler и LibreOffice.
Русская модель OCR включена в установщик. Для загрузки недостающих компонентов
нужен интернет; сама программа обрабатывает документы локально.

Из исходников можно запустить `install-windows.bat` — он использует те же проверки
и спрашивает об установке недостающих компонентов и LibreOffice.
Пошагово — [`windows-installation.txt`](windows-installation.txt),
сборка установщика — [`packaging/windows/README.md`](packaging/windows/README.md).

### Зависимости

Python-библиотеки — [`requirements.txt`](requirements.txt):

```bash
pip install -r requirements.txt
```

Внешние программы: `libreoffice` (конвертация в PDF/Word), `tesseract-ocr` + `tesseract-ocr-rus`
(распознавание Ф-9), `poppler-utils` (`pdftoppm`, `pdfunite`, `pdftotext`).

## Как пользоваться

При запуске из репозитория: `.venv/bin/python app/desktop_app.py`.
Папка входящих файлов — `incoming/`; после установки — `~/Desktop/filing/incoming/`.
Программа создаёт папки `output/`, `output-family/`, `output-consumer/`,
`output-contracts/`, `scans/`, `scans-family/`, `scans-consumer/` и
`contract-templates/` внутри папки приложения по мере использования.

1. Откройте СОВА и выберите направление в боковой панели.
2. **«Выбрать файлы»** — загрузите расчёт и сканы для распознавания.
3. **«Открыть таблицу / анкету»** — проверьте данные и сохраните исправления.
4. **«Создать документы»** — получите документы в папке `output/` соответствующего раздела.
   Проверьте `validation-report*.txt` и откройте документы в Word / LibreOffice.

На Windows входящие файлы можно хранить в `incoming/` внутри папки установки
(`%LOCALAPPDATA%\Programs\OwlLawyer` по умолчанию).

Полный цикл показывает демо-набор в `incoming/demo/` — все данные в нём
**вымышленные**: компания «ООО „Рога и Копыта“», адреса «Примерная область, Примерный
район, г. Пример», паспорта `40**-******`, счёт `407028****2345`. Печать на демо-справках
нарисована с нуля.

## Приватность

- Программа не ходит в сеть: ни телеметрии, ни отправки данных.
- **Персональные данные должников в репозиторий не попадают** — таблицы ввода, сканы
  Ф-9, распознанные паспорта и папки `output*` исключены в `.gitignore`.
- Всё демо-контент в репозитории — вымышленный. Реальные данные живут только в вашем
  рабочем каталоге.
