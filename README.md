# 🦉 Сова-юрист

Автоматизация юриста по взысканию задолженности за ЖКУ. Локальное desktop-приложение
на Python + Tkinter: превращает расчёт бухгалтерии и сканы справок Ф-9 в готовые
судебные приказы и исковые заявления.

Работает **только на вашем компьютере**. Интернет не используется, персональные данные
никуда не отправляются.

Три раздела:

| Раздел | Что делает |
|---|---|
| **Жилищное право (ЖКУ)** | Расчёт бухгалтерии («Портянка») + сканы справок Ф-9 → таблица ввода → судебные приказы и иски (.docx) + реестр и отчёт сверки. Номер лицевого счёта распознаётся **автоматически** из текста каждой справки; страница привязывается к своему счёту, а не «наугад». |
| **Семейное право** | Сканы (паспорт истца, свидетельство о браке, свидетельства о рождении детей) → анкета → иск о расторжении брака, взыскании алиментов и определении места жительства детей. |
| **Защита прав потребителя** | Сканы (паспорт, претензия, чек) → анкета → иск: возврат денег / замена / устранение недостатков + неустойка + моральный вред + штраф 50 %. |

## Установка

### Linux (Debian / Ubuntu / Mint)

```bash
bash УСТАНОВКА-Линукс.sh
```

Скрипт поставит зависимости, скопирует программу в `~/Desktop/Генератор`, создаст
ярлыки «Сова-юрист», «1 Загрузить данные», «2 Собрать документы» и проверит
цепочку демо-прогоном.

Если зависимости уже стоят: `SOVA_SKIP_APT=1 bash УСТАНОВКА-Линукс.sh`

### Windows

1. Поставьте Python 3.9–3.14, Tesseract OCR (с языковым пакетом **RUSSIAN**),
   Poppler и LibreOffice — ссылки в [`windows-загрузки.txt`](windows-загрузки.txt),
   пошагово — в [`Инструкция-Виндовс.txt`](Инструкция-Виндовс.txt).
2. Запустите `УСТАНОВКА-Виндовс.bat`.

### Зависимости

Python-библиотеки — [`requirements.txt`](requirements.txt):

```bash
pip install -r requirements.txt
```

Внешние программы: `libreoffice` (конвертация в PDF/Word), `tesseract-ocr` + `tesseract-ocr-rus`
(распознавание Ф-9), `poppler-utils` (`pdftoppm`, `pdfunite`, `pdftotext`).

## Структура репозитория

```
приложение/        программа «Сова-юрист» (Python, 14 скриптов)
шаблоны/           6 эталонных шаблонов СП/исков (.doc) — образец, программой не читается
иконки/            иконка приложения (сова в очках с портфелем)
подача-входящие/   папка-приёмник входящих файлов
  демо-пример/     ДЕМО-НАБОР: «Портянка» + «Ф-9 (демо-справки).pdf» (5 страниц)
УСТАНОВКА-Линукс.sh, УСТАНОВКА-Виндовс.bat
Инструкция-Виндовс.txt, windows-загрузки.txt
Чек-лист-проверки.txt   что нажать и что должно появиться
```

## Как пользоваться

1. Положите в `~/Desktop/подача/входящие` расчёт бухгалтерии и сканы справок Ф-9.
2. Ярлык **«1 Загрузить данные»** — импорт: распознавание, таблица ввода, отчёт сверки.
3. Ярлык **«2 Собрать документы»** — судебные приказы и иски в папку `Выход/`.
4. Проверьте `Отчёт-сверки.txt` и откройте документы в Word / LibreOffice.

Полный цикл показывает демо-набор в `подача-входящие/демо-пример/` — все данные в нём
**вымышленные**: компания «ООО „Рога и Копыта“», адреса «Примерная область, Примерный
район, г. Пример», паспорта `40**-******`, счёт `407028****2345`. Печать на демо-справках
нарисована с нуля.

## Приватность

- Программа не ходит в сеть: ни телеметрии, ни отправки данных.
- **Персональные данные должников в репозиторий не попадают** — таблицы ввода, сканы
  Ф-9, распознанные паспорта и папки `Выход*` исключены в `.gitignore`.
- Всё демо-контент в репозитории — вымышленный. Реальные данные живут только в вашем
  рабочем каталоге.
