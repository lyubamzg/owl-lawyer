УСТАНОВКА СОВА НА WINDOWS
=========================

Рекомендуемый вариант: SOVA-Setup-0.2.0-x64.exe
---------------------------------------------
Поддерживаются Windows 10 (1809+) и Windows 11, процессор x64.
Для первой установки требуется интернет. Само приложение работает локально.

1. Запустите SOVA-Setup-0.2.0-x64.exe двойным кликом.
2. Оставьте включённой установку отсутствующих компонентов:
   Python 3.11–3.14 (64-bit с Tkinter и pip), Tesseract OCR и Poppler.
   Уже подходящие установленные программы используются повторно.
3. Отдельная галочка предлагает LibreOffice. Если он уже установлен,
   повторной установки не будет. Без LibreOffice редактирование таблиц
   и конвертация документов будут недоступны.
4. Нажмите «Установить». Для сторонних программ Windows может запросить
   разрешение администратора. Загрузка идёт через Windows Package Manager
   (WinGet); установка принимает условия выбранных пакетов и источника.
5. После завершения откройте СОВА через меню «Пуск» или ярлык на рабочем столе.

Приложение устанавливается для текущего пользователя:
  %LOCALAPPDATA%\Programs\OwlLawyer
Библиотеки Python находятся в отдельном runtime и не меняют библиотеки
других программ. Русская модель OCR включена в установщик.
Ручная настройка PATH не требуется.

ВАЖНО: первая сборка не подписана сертификатом издателя.
Windows может показывать предупреждение о неизвестном издателе.
Распространяйте установщик из доверенного источника; подпись будет нужна
для выпуска, рассчитанного на широкое распространение.

Обновление и удаление
--------------------
Повторно запустите установщик для обновления или восстановления.
Существующая input-workbook.xlsx не перезаписывается.
Рабочие книги, папки output*, scans*, incoming и изменённые шаблоны
сохраняются при обновлении и удалении приложения.
Удаление доступно через «Параметры → Приложения → СОВА».
Python, Tesseract, Poppler и LibreOffice удаляются отдельно своими
установщиками, если больше не нужны.

Если установка остановилась
--------------------------
Журнал: %LOCALAPPDATA%\OwlLawyer\Logs\setup.log
Если нет WinGet, установите или обновите «Установщик приложений»
(App Installer) в Microsoft Store: https://aka.ms/getwinget
Если установка сторонней программы требует перезагрузки,
перезагрузите Windows и повторите установку СОВА.
Если нет прав администратора, попросите администратора заранее
установить недостающие сторонние программы.

Установка из исходников (без готового EXE)
---------------------------------------
1. Распакуйте весь репозиторий, включая packaging/windows.
2. Запустите install-windows.bat. Ответьте Y или N на два вопроса:
   установка отсутствующих компонентов и установка LibreOffice.
3. Скрипт подготовит тот же отдельный runtime, скопирует программу
   в %LOCALAPPDATA%\Programs\OwlLawyer и создаст ярлыки SOVA.
Этот способ не регистрирует программу удаления; для обычных пользователей
рекомендуется готовый Setup.exe.
